# MiniBank

MiniBank is a Java console banking project for Part B of the OOPJ practicals. You can open accounts, deposit and withdraw money, transfer between accounts, view account statements, run transaction reports, and process a batch of deposits. Account balances are saved when you exit and restored the next time you run the program.

## Requirements

- JDK 17 or later
- A terminal opened in the project root

The project uses Java source files only; no external libraries are required.

## Compile and run

Compile the application into a local output directory:

```sh
mkdir -p out
javac -d out MiniBank.java $(find model service util -name '*.java')
```

Start MiniBank:

```sh
java -cp out MiniBank
```

The `out/` directory contains compiled classes and is ignored by Git.

## Using the menu

Choose a menu number and follow the prompts:

| Option | What it does |
| --- | --- |
| 1. Open account | Creates an account after collecting the owner's name, email, mobile number, and opening balance. |
| 2. Deposit | Adds a positive whole-rupee amount to an account. |
| 3. Withdraw | Withdraws an amount if the account has enough available funds. |
| 4. Transfer | Moves an amount between two existing accounts. |
| 5. View statement | Shows the account number, owner, current balance, and status. |
| 6. Run report | Summarizes deposits and withdrawals recorded in transaction logs. |
| 7. List accounts | Displays all accounts currently loaded in the application. |
| 8. Batch deposit | Applies several comma-separated deposits to one account using the transaction processor. |
| 9. Exit | Saves account data and closes the application. |

New accounts require a valid email, a 10-digit Indian mobile number beginning with 6–9, and a positive opening balance. Deposits and withdrawals must also be positive amounts. If a transaction cannot be completed, MiniBank displays an error and returns to the menu.

## Data and reports

MiniBank creates a `data/` directory in the current working directory:

- `data/accounts.dat` stores account state. The program saves it when you choose Exit and loads it at startup.
- `data/logs/transactions.log` records completed deposits, withdrawals, and transfers.
- `data/report.txt` is generated by the Run report option and includes totals and log-file details.

Keep the `data/` directory if you want to retain accounts between runs. Deleting it removes the saved account state and reports.

## Example customer session

For a new customer, choose **1. Open account** and enter:

```text
Owner name: Riya Patel
Email: riya@example.com
Mobile: 9876543210
Opening balance: 10000
```

MiniBank confirms the new account number (for example, `AC0001`). Use that number for deposits, withdrawals, statements, and transfers. Choose **9. Exit** to save the account before closing.

## Project layout

```text
MiniBank.java
model/
service/
util/
```

`model/` contains account and customer types, interfaces, and validation annotations. `service/` contains banking operations, storage, command parsing, and transaction processing. `util/` contains input validation, persistence, log reporting, and statement formatting.
